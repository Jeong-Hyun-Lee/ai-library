# StepFun, 600B MoE 플래그십 "Step 5 Preview" 공개

중국 스타트업 [[stepfun|StepFun]]이 2026-09-20 장기 실행 에이전트 작업에 특화한 플래그십 모델 Step 5 Preview를 공개하고 API를 동시 개방했다.

## 핵심 내용

- 총 6,000억 파라미터 MoE(전문가 혼합) 구조, 토큰당 활성 파라미터 270억, 컨텍스트 100만 토큰, 출력 최대 6만4,000토큰.
- 텍스트·이미지·비디오 입력 지원, 소프트웨어 엔지니어링·장시간 에이전트 작업·전문 지식 업무·금융 분석에 특화.
- 가격은 입력 100만 토큰당 1.00달러, 출력 100만 토큰당 2.70달러.
- 오픈 가중치는 2026-10-15 공개 예정 — API 우선 출시 후 오픈소스 공개하는 전략.
