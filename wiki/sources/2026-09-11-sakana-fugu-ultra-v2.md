# Sakana AI, 오케스트레이션 모델 Fugu Max·Fugu Ultra v2.0 출시

일본 도쿄 소재 [[sakana-ai|Sakana AI]]가 2026-09-11 Fugu 시스템의 신버전 Fugu Max v1.0과 Fugu Ultra v2.0을 출시했다. 단일 모델이 아니라 여러 모델을 조율하는 "오케스트레이터"라는 점이 특징이다.

## 핵심 내용

- Fugu는 하나의 요청을 받아 내부적으로 여러 모델 풀 중 적합한 모델에 작업을 배분하고 결과를 조합해 하나의 API 응답으로 반환하는 방식
- 시각적 추론·데이터 해석 벤치마크 Chartography에서 48.3점 기록 — Anthropic Opus 5(27.3점), Fable 5(29.5점)를 상회. Fable 5·5.1이나 GPT-6 Astra를 에이전트 풀에 포함하지 않고 달성
- 가격: Fugu Ultra v2 표준 컨텍스트 기준 입력 $5/출력 $30(백만 토큰당), 캐시 입력 $0.50, 27.2만 토큰 초과 구간은 $10/$45/$1.00로 상승
- OpenAI 호환 API로만 제공되는 호스티드 서비스, EU·EEA 지역에서는 미제공
