# DeepSeek, 첫 멀티모달 실험 모델 V4-Flash-Vision-Exp 오픈소스 공개

DeepSeek이 2026-08-31 [[deepseek|DeepSeek]] V4 패밀리 최초의 멀티모달 모델 V4-Flash-Vision-Exp의 가중치를 Hugging Face에 MIT 라이선스로 공개했다. 2026-08-21 API 전용 프리뷰로 처음 등장한 지 열흘 만에 오픈 가중치로 전환됐다.

## 핵심 내용

- MoE 백본 2,840억 파라미터(비전 타워·얼라이너 등 부가 모듈 포함 시 Hugging Face 메타데이터 기준 3,050억)
- 이미지·스크린샷·시각적 프롬프트를 분석하면서 기존 텍스트·추론·에이전트 역량은 그대로 유지
- "사람이 아닌 에이전트가 보기 위한 눈"이라는 컨셉으로, 에이전트 작업에 특화된 비전 능력에 초점
- MIT 라이선스로 가중치 공개, DeepSeek 자체 제공 MoE 백본 파라미터 수(2,840억)와 Hugging Face 메타데이터(3,050억) 간 표기 차이 존재
