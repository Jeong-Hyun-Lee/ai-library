# OpenAI, GPT-6 Sol·Luna 출시 — API 가격 50% 영구 인하

OpenAI가 2026-09-22 [[gpt|GPT-6]] 라인업의 중저가 티어 Sol과 Luna를 출시하며 GPT-5.6 대비 API 가격을 50% 인하했다. OpenAI 대변인은 프로모션이 아닌 영구 가격이라고 확인했다.

## 핵심 내용

- GPT-6 Sol: 입력 100만 토큰당 2달러, 출력 100만 토큰당 10달러.
- GPT-6 Luna: 입력 100만 토큰당 0.10달러, 출력 100만 토큰당 0.50달러 — 대량 사무 처리용 최저가 티어.
- 기존 플래그십 [[astra|Astra]](입력 10달러/출력 50달러)와 함께 3단계 가격 체계 완성 — 엔터프라이즈급 추론부터 대량 저비용 작업까지 전 구간 커버.
- 업계 전반의 "속도 조절론" 논의 속에서도 가격·비용 경쟁은 계속 심화되는 흐름을 보여줌.
