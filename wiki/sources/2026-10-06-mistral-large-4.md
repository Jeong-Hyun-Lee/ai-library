# Mistral, 1조 파라미터 모델 "Large 4(르 쇵크)" 프리뷰 공개

[[mistral|Mistral]]이 2026-10-06 애칭 "Le Chonk"로 불리는 신형 모델 Large 4를 API 프리뷰로 공개했다.

## 핵심 내용

- 총 1조 파라미터(활성 490억) 멀티모달 MoE — 텍스트·이미지 입력을 받아 텍스트로만 응답, 비전 인코더는 16억 파라미터, 컨텍스트 100만 토큰.
- 자체 클러스터(Nvidia Grace Blackwell GPU 3,800개)로 학습했으나, Mistral은 실제 학습에는 4,000개 GPU만 사용했다고 강조 — "중국 경쟁사 대비 2~3배 적고, 폐쇄형 경쟁사보다도 훨씬 적은" 자원으로 학습했다는 효율성을 부각.
- 오픈 가중치 공개는 10월 말(현재 예상일 10/31) 예정.
