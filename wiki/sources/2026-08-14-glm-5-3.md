# GLM-5.3 출시

Z.ai가 2026-08-14 [[glm|GLM]]-5.3을 출시했다. GLM-5.2와 동일한 베이스 모델(743B)을 재사용하고, post-training 확장만으로 성능 향상을 이뤘다는 점이 특징이다.

## 핵심 내용

- Terminal-Bench 3.0 점수를 4.6%에서 28.3%로 끌어올림 (post-training만으로)
- Z.ai Code Bench 기준 GLM-5.2 대비 50% 향상, 자체 평가 기준 최강 오픈웨이트 코딩 모델이라 주장
- 사이버보안 역량이 학습 과정에서 예상보다 빠르게 성장 — Cursor에서 실제 취약점을 발견했다고 보고
- API에서 thinking effort 3단계(low/high/max) 지원, thinking 끄기 옵션은 제거(breaking change)
- 가중치는 안전성 평가 후 약 2주 뒤 공개 예정, 현재는 API·GLM Coding Plan으로만 제공
