# OpenAI, 미출시 모델 Astra의 "Critical" 사이버 역량 가능성 공개

OpenAI가 2026-08-07 미출시 모델 [[astra|Astra]]의 내부 예비 평가에서 Preparedness Framework 기준 "Critical" 등급의 사이버보안 역량을 배제할 수 없다고 공개했다. 자사 프레임워크상 Critical 등급이 언급된 최초 사례다.

## 핵심 내용

- Preparedness Framework의 Critical 등급은 모델이 사람의 도움 없이 강화된 실제 시스템에 대해 제로데이 취약점을 독자적으로 발견·개발하거나 폭넓은 목표로부터 정교한 사이버공격을 수행할 수 있는 경우를 의미
- OpenAI는 Astra가 아직 Critical 등급으로 "확정"된 것은 아니며 평가가 진행 중이라고 명시
- 에이전틱 코딩·사이버보안 역량에서 뚜렷한 도약이 관측되어, 해당 등급을 배제할 수 없다는 결론에 도달
- 대응으로 Astra 개발 속도를 늦추고, 강화된 보안 요건을 충족하지 못하는 활동을 일시 중단, 정부기관·안전기구와 추가 테스트 준비 중
