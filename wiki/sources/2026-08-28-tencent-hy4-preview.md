# Tencent, Hy4 Preview 오픈소스 공개

Tencent Hunyuan(混元)팀이 2026-08-28 플래그십 모델 [[hy|Hy4]] Preview를 Apache 2.0 라이선스로 오픈소스 공개했다. 자신의 학습 과정 설계를 도왔다는 재귀적 자기개선(recursive self-improvement) 사례로도 소개된다.

## 핵심 내용

- MoE 아키텍처, 총 파라미터 7,700억 / 활성 파라미터 490억, 컨텍스트 윈도우 100만 토큰 이상
- 코딩·사무·과학 연구 등 실무 생산성 과제에서 강한 성능을 보인다고 주장
- 여러 Codex 세션을 병렬로 조율·평가해 연구 방향을 조정하는 에이전틱 리서치 역량을 시연, 8개 벤치마크에서 단독 Codex를 능가했다고 발표
- WorkBuddy, CodeBuddy, Yuanbao, ima 등 Tencent 제품과 Tencent Cloud TokenHub, OpenRouter API로 접근 가능
- WorkBuddy·CodeBuddy는 2주간 무료 제공, API 가격은 입력 $0.834/출력 $2.501(백만 토큰당)
