# Runway, "Interface World Model" Solaris 공개

Runway가 2026-08-31 새로운 모델 범주 "Interface World Model"의 첫 모델 [[solaris|Solaris]]를 공개했다. 코드 계층 없이 사용자 인터페이스를 실시간으로 프레임 단위 생성해 구동하는 방식이다.

## 핵심 내용

- 디자인과 실행 앱 사이의 중간 표현(코드)을 없애고, 사용자 상호작용에 대한 모든 화면·응답을 하나의 world model이 프레임 단위로 직접 생성
- Runway의 비디오 생성 모델 Gen-4.5를 기반으로 구축
- 250명 참가자 대상 선호도 조사에서 지시사항 이행 기준 기존 코드 기반 인터페이스보다 61% 더 선호됨
- 아직 가독성 있는 텍스트 처리, 상업적 신뢰성 확보, 장시간 세션에서의 일관성, 스크린리더 등 접근성 도구 통합은 미해결 과제로 남음
- 현재 공개 제품으로 출시되지 않았으며, 주요 파트너 대상 협업과 얼리엑세스 신청폼을 통해 공개 출시를 준비 중
