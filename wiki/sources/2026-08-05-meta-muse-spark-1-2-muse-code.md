# Meta, Muse Spark 1.2 및 터미널 코딩 에이전트 Muse Code 공개

Meta Superintelligence Labs가 2026-08-05 신모델 [[muse|Muse]] Spark 1.2와 이를 구동 엔진으로 쓰는 터미널 코딩 에이전트 Muse Code(베타)를 공개했다. Meta의 AI 코딩 경쟁 진입을 알리는 출시다.

## 핵심 내용

- Muse Spark 1.2는 컨텍스트 윈도우 100만 토큰, 코드 첫 시도 정확도 개선, 지속적 비동기 백그라운드 에이전트와 긴밀히 통합
- 대규모 코드베이스 디버깅, 수천 개 파일에 걸친 변경 검증, 다단계 추론 과제에 특화
- Muse Code는 병렬 서브에이전트, worktree 격리, 크래시에도 안전한 이벤트 로그를 특징으로 하는 터미널 코딩 에이전트
- Muse Spark 1.2는 출시 시점에 비공개(closed) 모델이며, Mark Zuckerberg가 향후 가중치 공개를 예고 — 2026-08-10 [[2026-08-10-meta-muse-glimmer|Muse Glimmer]] 공개와 함께 "곧" 공개하겠다고 재확인했으나 구체적 일정은 미정
