# Claude Opus 5 출시

Anthropic이 2026-07-24 [[claude|Claude]] Opus 5를 출시했다. 전작 Opus 4.8과 동일한 가격을 유지하면서 Claude Fable 5에 근접한 프론티어 지능을 절반 가격에 제공한다는 점이 특징이다. 두 달도 안 되는 기간 안에 나온 네 번째 Claude 5 모델 출시로, AI 업계가 대형 단일 출시보다 빠른 반복 개선 방식으로 옮겨가고 있음을 보여준다.

## 핵심 내용

- 가격은 Opus 4.8과 동일하게 유지 (입력 $5/M, 출력 $25/M 토큰)
- Reasoning effort를 low/medium/high/max로 조절하는 "effort dial" 도입 — max effort 기준 Opus 4.8 대비 토큰 26% 절감
- Frontier-Bench v0.1에서 전 모델 중 최고 점수, Opus 4.8 대비 2배 이상 성능
- CursorBench 3.2(max effort)에서 Fable 5 최고 점수의 0.5% 이내, 비용은 절반
- OSWorld 2.0(컴퓨터 사용 벤치마크)에서 Fable 5 최고 기록을 능가하면서 비용은 1/3 수준
- ARC-AGI 3에서 차순위 모델 대비 3배 점수
- 컨텍스트 윈도우 100만 토큰, 지식 컷오프 2026년 5월(Claude 모델 중 최신)
- Claude Max의 기본 모델, Claude Pro에서 가장 강력한 모델로 제공, API명 `claude-opus-5`
