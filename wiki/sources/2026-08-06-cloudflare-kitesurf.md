# Cloudflare, Kitesurf 출시

Cloudflare가 2026-08-06 AI 에이전트 전용 브라우저 런타임 [[kitesurf|Kitesurf]]를 공개했다. Cloudflare Workers의 V8 아이솔레이트에서 완전히 구동되는, 에이전트 네이티브 브라우저로 소개된다.

## 핵심 내용

- Chromium 대비 일반적인 에이전트 작업에서 CPU·메모리 사용량 3~7배 절감
- 23만 5천 개 이상의 Web Platform Tests 통과(DOM 서브테스트 97%, HTML 서브테스트 96%)
- 기존 Puppeteer, Playwright, MCP 클라이언트와 호환되는 CDP 엔드포인트 제공
- 첫 커밋은 2026년 5월, 약 12주 만에 프로덕션 베타로 출시
- Browser Rendering 제품 안에서 베타 기간 무료 제공
