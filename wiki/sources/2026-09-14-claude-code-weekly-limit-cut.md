# Anthropic, Claude Code 주간 사용한도 사실상 17% 축소 — "인상"이라는 표현에 반발

Anthropic이 2026-09-14부터 [[claude|Claude]] Code의 표준 주간 사용한도를 기존 기준선 대비 영구 25% 인상한다고 발표했다. 그러나 그동안 임시로 적용되던 50% 한도 증량이 같은 날 종료되면서, 직전 대비로는 실질 17% 감소 효과가 발생했다.

## 핵심 내용

- Pro, Max, Team, 좌석 기반 Enterprise 플랜에 적용
- 계산 예시: 기존 기준선이 100이라면 임시 증량으로 150까지 늘었다가, 9/14부터 기준선의 125로 하향 조정 — 현재 사용자 입장에서는 16.7%(반올림 17%) 감소
- Anthropic의 최초 공지가 "25% 인상"만을 강조하고 실질 감소분을 명시하지 않아 X(트위터)에서 개발자들의 반발을 삼 — Anthropic은 게시물을 삭제하고 17% 감소를 명시한 정정 공지를 재게시
- 공지 시점이 Amodei의 AI 속도 조절 촉구 발언, GPT-6 Astra 출시 확산과 겹치며 업계 전반의 비용·거버넌스 논의 속에서 나옴
