# DeepSeek V4-Pro GA 출시

DeepSeek이 2026-08-13 플래그십 모델 [[deepseek|DeepSeek]]-V4-Pro(빌드명 0813)를 프리뷰에서 정식(GA) 전환했다. 자율 에이전트 운용에 초점을 맞춘 대규모 업그레이드가 특징이다.

## 핵심 내용

- MoE 아키텍처, 총 파라미터 1.6조 / 토큰당 활성 파라미터 490억
- 컨텍스트 윈도우 100만 토큰, 단일 요청 최대 출력 38.4만 토큰
- 작업 난이도에 따라 low/standard/max 추론 모드를 선택하는 적응형 reasoning 도입
- OpenAI Responses API를 네이티브 지원해 기존 개발 생태계와의 통합 용이
- 2026-08-16 16:00 UTC부터 V4 패밀리 가격 인상, 피크/오프피크 이원 요금제 도입(오프피크는 피크의 절반)
