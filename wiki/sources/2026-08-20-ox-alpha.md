# OX Alpha 스텔스 모델 등장

2026-08-20 OpenRouter에 `stealth/ox-alpha`라는 식별자로 정체불명의 무료 코딩 모델 [[ox-alpha|OX Alpha]]가 등장했다. 제작사를 자처하는 곳이 없어 AI 커뮤니티에서 화제가 되고 있다.

## 핵심 내용

- 컨텍스트 윈도우 1,048,576토큰, 출력 최대 131,072토큰, 텍스트·이미지·비디오 입력 지원
- 1주일간 무료 제공(OpenRouter는 2026-08-24까지, OpenCode 공지는 2026-08-20 기준 1주일 후인 8/27경까지로 안내해 종료 시점이 불일치)
- 비공식 10개 과제 테스트에서 DeepSWE 벤치마크 80% 기록 — Claude Fable 5(65%), GPT-5.6 Sol(52%)을 앞섬. 다만 감사된 리더보드가 아닌 소규모 사용자 테스트 결과라 예비적 수치로 취급해야 함
- 비디오 인코더 토큰 사용 패턴이 GLM-5V-Turbo와, 토크나이저가 GLM-5.3과 일치하고, 오디오 입력 거부 방식·이모지 사용 빈도 등이 Zhipu AI(Z.ai)의 [[glm|GLM]] 모델과 유사하다는 정황 증거가 제기됨 — 다만 Zhipu 측의 공식 확인은 없어 출처는 여전히 미확정
